# Logo usage

All logos are SVG with the text already turned into shapes (Archivo weight 900), so they look the same everywhere, even without the font. The monogram is CF.

| File | Use it for |
|---|---|
| logo-primary.svg | Main logo on white or light backgrounds (website header, invoices). |
| logo-reversed.svg | Main logo on black. It has its own black background. |
| logo-stacked.svg | Square places: social profile, packaging label, hang tag. |
| icon.svg | Favicon, app icon, small sizes. Keep at least 24px wide. |
| logo-mono-black.svg | One-colour printing on light garments. Ink: #111111. |
| logo-mono-white.svg | One-colour printing on dark garments. Ink: white. The black background is only for preview; remove it for print. |

Rules: keep clear space around the logo equal to half the height of the tile. Never stretch it. Never put the yellow tile on a yellow background.


Files live in `public/brand/`. The favicon is `public/favicon.svg`.
